# Aprendiendo Git y GitHub 🚀

Proyecto inicial creado por Camila para aprender y practicar el control de versiones con Git.

## Comandos basicos aprendidos:
- `git init`: Inicializa un nuevo repositorio.
- `git status`: Revisa el estado de los archivos.
- `git add <archivo>`: Agrega archivos al area de preparacion (staging).
- `git commit -m "mensaje"`: Guarda una nueva version con una descripcion.
- `git log`: Muestra el historial de commits.
